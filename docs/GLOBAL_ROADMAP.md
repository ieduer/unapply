## 0. 最終目標（站長 2026-11-06 口述，整理）

1. 站點從「只有中國大陸」補充完善為**全球學生都能使用**的學校減法站。
2. 流程先問**用戶所在國家／地區**，之後按用戶的選擇繼續用**詢問（減法）**的方式，
   最終完成**專業與學校的推薦**；加入不同語言。
3. 不同地區的學生可以**跨國選擇**：所在地只決定起點與可申請管道，不限制終點。
4. 建立**全球高校信息權威資料庫**，同時可檢索**招生等情況**（專業、錄取條件、
   可能的招生政策——尤其是專業）。
5. 近幾年一些頂尖公司**繞過高校直接招高中學生**（fellowship、企業學位、全職預備研究員等），
   這類「非大學路徑」也列入資料庫與減法選項。
6. 目標先寫入項目，分階段推進，避免一次做得過大。

以上是終點。下面每一階段都必須能獨立發布、獨立回滾，並沿用本站既有原則：
疑罪從無、官方主表優先、中性展示、判斷權在用戶、非商業、不提供志願填報建議、
不設教師覆核、學習資料留存但不存個人資料。

- **資料權威分級**：P0 官方（教育部、各國教育主管機關、學校官網招生頁）→ P1 權威第三方（軟科 GRAS、QS、THE、US News 等有公開方法論的排名；Wikidata 僅作地理與名稱對照）→ P2 眾包。
  排名只用來**描述學科分佈**，不作為錄取可能性或「推薦」依據。
  **現況（批 F1）**：`data/research/authority_tiers.2026-11-07.csv` 106 條規則（＋ gov／edu 網域型態），站內來源鏈接旁標「官方／權威平台／第三方」，About 有「權威分級說明」；資料庫 `/db/v1` 的每條來源都帶分級（批 F2）。
- **對外鏈接規則**（站長 2026-11-06）：能加權威資料鏈接就加，但每條必須核查是官方或權威：來源可追溯、實際連通、網域與機構一致；
  核查不過的不上線，記在資料檔的 `status` 欄供人工覆核；每年隨排名更新重核。
  **現況（批 F1）**：全站 6,139 條去重鏈接的年檢基線入庫（`data/research/link_check.2026-11-07.csv.gz`＋summary）；非校網壞鏈 6 處與 school_websites 跨網域轉址 5 處已修（GRAS 官網兩所轉址因是 S3 錨點暫緩）；年度工具 `npm run audit:links`（不進閘門，手冊 §3.9）。
- **跨國規則**：所在地只影響「可申請管道」與「前幾題怎麼問」，不預設剔除任何國家；用戶自己劃掉的才消失。
- **不越界**：不做志願填報預測、不做錄取機率、不做付費諮詢；AI 僅在站長授權的範圍內用於解釋與整理，不替用戶決定。

## 4. 已知限制（S0）

- 排名反映研究產出，不反映本科教學、錄取難度或學費；頁面必須寫明。
- 大陸以外機構目前只有「在哪些學科前列」，沒有專業、錄取條件、學費——那是 S3 的事。
- 「其他國家或地區」目前只是一個起點，沒有對應題庫；頁面要明說，不要假裝有。
- 企業直招條目隨招募年度變動，站內只保證核對日當天為真。
